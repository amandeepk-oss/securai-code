# SecurAI Code - OWASP Security Code Auditor

SecurAI Code is an AI-powered security auditing micro-SaaS that analyzes source code for OWASP Top 10 vulnerabilities, exposed secrets, and injection risks using Google Gemini 2.5 Flash API.

## 🚀 Features
- **Instant Security Audit**: Scans Python, JavaScript, Java, and C++ source code.
- **OWASP Risk Scoring**: Provides security score (0-100) and severity ratings.
- **Automated Remediation**: Generates secure, refactored code fixes instantly.
- **Modern Dark UI**: Fast, responsive interface powered by FastAPI & Tailwind CSS.

## 🛠 Tech Stack
- **Backend**: FastAPI, Python 3.10+, Pydantic
- **AI Engine**: Google Gemini 2.5 Flash (`google-genai` SDK)
- **Frontend**: Jinja2, Tailwind CSS, JavaScript (Fetch API)
